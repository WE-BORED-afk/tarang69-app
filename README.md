# TARANG69 Mobile App (Flutter & Home Screen Widget) 📱✨

แอปพลิเคชันตารางเรียน ม.6/9 พัฒนาด้วย **Flutter** พร้อมฟังก์ชัน **Home Screen Widget** สำหรับ Android และพร้อมต่อยอดไปยัง iOS (WidgetKit)

## ฟีเจอร์หลัก (Features)
- 📲 **Home Screen Widget:** ปักหมุดบนหน้าจอมือถือ แสดงวิชาที่กำลังเรียน เวลา คาบถัดไป และห้องเรียนได้แบบเรียลไทม์
- 🔄 **Single Source of Truth:** ดึงข้อมูลตารางเรียนส่วนกลางจาก GitHub อัตโนมัติ อัปเดตตารางที่เดียว ทั้งเว็บและแอปเปลี่ยนพร้อมกัน
- 📴 **Offline First:** ใช้งานได้แม้ไม่มีอินเทอร์เน็ตผ่าน local asset & cache
- 🔔 **4 Bell Plans:** รองรับการเลือกแผนเวลาเรียนทั้ง 4 แผนของโรงเรียน
- 🚀 **Auto-Build APK:** มีระบบ GitHub Actions คอมไพล์เป็นไฟล์ `.apk` พร้อมให้ดาวน์โหลดติดตั้งได้ทันที

## วิธีติดตั้ง Widget บน Android
1. ดาวน์โหลดไฟล์ `app-release.apk` จากหน้า [Releases](https://github.com/WE-BORED-afk/tarang69-app/releases) มาติดตั้งบนมือถือ
2. เปิดแอป TARANG69 ขึ้นมาหนึ่งครั้งเพื่อให้ระบบลงทะเบียนข้อมูล
3. ไปที่หน้าจอหลัก (Home Screen) ของมือถือ แล้วกดค้างที่พื้นที่ว่าง
4. เลือกเมนู **Widgets** > ค้นหา **TARANG69** > ลากมาวางบนหน้าจอหลักได้ทันที
